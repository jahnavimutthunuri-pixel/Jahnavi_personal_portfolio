# Aasritha — Personal Portfolio

A responsive, accessible personal portfolio built with HTML5, CSS3, Bootstrap 5 and vanilla JavaScript (ES6+).

## Features
- Semantic sections: Home, About, Education, Skills, Projects, Achievements and Contact.
- Mobile-first layout with CSS Grid/Flexbox principles, media queries and Bootstrap responsive grid.
- Bootstrap navbar, cards, buttons, form controls, table and responsive utilities.
- Dark/light theme switcher.
- Project category filters with accessible pressed states.
- Client-side contact form validation with inline feedback and focus management.
- Keyboard skip link, semantic landmarks, labels, table caption, aria-live feedback and reduced-motion support.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser. An internet connection is required for Bootstrap, Bootstrap Icons and Google Fonts CDNs.
3. For a local development server, run `python -m http.server 8000` in the project folder and visit `http://localhost:8000`.

## Before submitting
Update the editable profile details in `index.html`:
- Add your real email, GitHub and LinkedIn profile links.
- Verify the education details and CGPAs shown in the portfolio.
- Add verified achievements/certifications only.
- Add GitHub repository links to projects after publishing them.
- Review project descriptions so they match the current implementation and your contribution.

## Contact form note
The form performs browser-side validation and displays a success message. It does not transmit or store submissions. Connect a backend or a trusted form service if message delivery is required.

## Deployment
Create a GitHub repository, upload all project files, then optionally enable GitHub Pages from **Settings → Pages** and select the branch/root folder. Add the repository and live URLs to the assignment report.
